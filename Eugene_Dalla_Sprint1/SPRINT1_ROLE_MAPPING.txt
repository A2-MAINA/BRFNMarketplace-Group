SPRINT 1 – EUGENE DALLA BACKEND RESPONSIBILITIES
===============================================

This index links each Sprint‑1 responsibility from
"sprint1_role_dependency_guide 2.docx" to the files in this folder.

1) Authentication API (register producer/customer, login, logout, profile)
------------------------------------------------------------------------
- users/views.py
  - ProducerRegisterView
  - CustomerRegisterView
  - LoginView
  - LogoutView
  - ProfileView
- users/serializers.py
  - ProducerRegisterSerializer
  - CustomerRegisterSerializer
  - LoginSerializer
  - UserProfileSerializer
- users/urls.py
  - Routes for:
    - POST /api/auth/register/producer/
    - POST /api/auth/register/customer/
    - POST /api/auth/login/
    - POST /api/auth/logout/
    - GET  /api/auth/profile/
- users/permissions.py
  - IsProducer and IsCustomer used to protect auth‑related flows

2) Role‑based permissions and access control
-------------------------------------------
- users/permissions.py
  - IsProducer: restricts product write operations to producers
  - IsCustomer: restricts cart operations to customers
  - IsOwner: checks that the authenticated user owns the resource
- products/views.py
  - Uses IsProducer for POST/PUT/PATCH/DELETE on products
- cart/views.py
  - Uses IsCustomer and IsOwner for cart operations

3) Product catalogue API (list, search, filter, detail)
------------------------------------------------------
- products/views.py
  - ProductListCreateView
    - GET /api/products/ with ?category= and ?search= filters
    - POST /api/products/ for producers to create products
  - ProductDetailView
    - GET/PUT/PATCH/DELETE /api/products/{id}/
  - CategoryList
    - GET /api/categories/
- products/urls.py
  - Routes for:
    - /api/products/
    - /api/products/<id>/
    - /api/categories/

4) Shopping cart API (add/view/update/remove, total)
---------------------------------------------------
- cart/models.py
  - Cart: one‑to‑one with User
  - CartItem: product + quantity within a cart
- cart/serializers.py
  - Serializers for CartItem and cart responses
- cart/views.py
  - CartView handling:
    - GET    /api/cart/
    - POST   /api/cart/
    - DELETE /api/cart/
- cart/urls.py
  - Route for /api/cart/
